description=[h2]What it does[/h2]
description=
description=Instead of checking attachments one at a time through separate menus, you can see the available slots, the currently installed parts, and compatible options together in one workbench.
description=
description=
description=
description=[h2]Features[/h2]
description=[list]
description=[*]Browse supported Guns of Marz firearms and their attachment slots in one place.
description=[*]See which parts are already fitted, which slots are empty, and which owned parts are compatible.
description=[*]Select several changes before committing them, like a practical installation cart.
description=[*]Build an installation queue, then have your character perform each installation individually.
description=[*]Use compatible parts from both your inventory and nearby containers/storage.
description=[*]Keep the work grounded in Project Zomboid: queued parts are not applied instantly.
description=[/list]
description=
description=[h2]How to use[/h2]
description=[olist]
description=[*]Open the Attachment Workbench.
description=[*]Choose a supported firearm or storage location from the left-hand list.
description=[*]Review the attachment slots and compatible parts.
description=[*]Add the changes you want to the work list.
description=[*]Start the queue and let your survivor install each selected part.
description=[/olist]
description=
description=[h2]Required mod[/h2]
description=[b]Guns of Marz[/b] is required. This is an add-on workbench and does not add its own firearms or attachment parts.
description=
description=[h2]Compatibility notes[/h2]
description=[list]
description=[*]Designed for Project Zomboid Build 42.
description=[*]Enable either current Guns of Marz or its bundled Old Version, not both. Gunworks Framework is required.
description=[*]Includes workbench access for vanilla firearms overridden by Simple Suppressors, including the M16 and JS shotguns.
description=[*]Improvised Silencers integration is included. For Simple Suppressors, use its own context menu if workbench installation is unavailable. GoM visual mappings for its suppressors are not included.
description=[*]Works with parts found in the player inventory and nearby storage.
description=[*]For multiplayer, install this mod and Guns of Marz on both the server and all clients.
description=[/list]
