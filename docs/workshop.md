[h2]What it does[/h2]
Guns of Marz: Attachment Workbench adds a dedicated attachment-management window for the firearms and firearm parts introduced by [b]Guns of Marz[/b].

Instead of checking attachments one at a time through separate menus, you can see the available slots, the currently installed parts, and compatible options together in one workbench.

[h2]Features[/h2]
[list]
[*]Browse supported Guns of Marz firearms and their attachment slots in one place.
[*]See which parts are already fitted, which slots are empty, and which owned parts are compatible.
[*]Select several changes before committing them, like a practical installation cart.
[*]Build an installation queue, then have your character perform each installation individually.
[*]Use compatible parts from both your inventory and nearby containers/storage.
[*]Keep the work grounded in Project Zomboid: queued parts are not applied instantly.
[/list]

[h2]How to use[/h2]
[olist]
[*]Open the Attachment Workbench.
[*]Choose a supported firearm or storage location from the left-hand list.
[*]Review the attachment slots and compatible parts.
[*]Add the changes you want to the work list.
[*]Start the queue and let your survivor install each selected part.
[/olist]

[h2]Required mod[/h2]
[b]Guns of Marz[/b] is required. This is an add-on workbench and does not add its own firearms or attachment parts.

[h2]Compatibility notes[/h2]
[list]
[*]Designed for Project Zomboid Build 42.
[*]Works with parts found in the player inventory and nearby storage.
[*]For multiplayer, install this mod and Guns of Marz on both the server and all clients.
[/list]

[h2]Credits[/h2]
Guns of Marz firearms and parts belong to their respective original mod authors. This add-on provides the attachment-management workflow.
